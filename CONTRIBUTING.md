# Contribuer

1. Créer une branche depuis `main`.
2. Installer les dépendances avec `make install-api install-web`.
3. Ajouter un test pour chaque comportement modifié.
4. Exécuter `make lint` puis `make test`.
5. Ouvrir une pull request courte décrivant le besoin métier et les limites.

Les commits suivent un style Conventional Commits : `feat:`, `fix:`, `docs:`,
`test:`, `refactor:` ou `chore:`.
