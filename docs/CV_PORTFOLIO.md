# Texte CV / portfolio

**GeoDashboard - Territorial Intelligence Studio**  
Conception d'une application SIG décisionnelle full-stack traitant un jeu de démonstration
open data de 103 équipements : contrôle qualité, analyse de couverture, simulation
d'implantations et génération de rapports PDF/exports SIG. Stack React, MapLibre,
FastAPI, GeoPandas et PostGIS ; 30 tests automatisés et moteur SQL sécurisé en lecture seule.

## Variante courte

Développement d'un studio SIG web permettant d'analyser la couverture territoriale de
103 équipements open data, de comparer des scénarios d'implantation et de générer des
livrables PDF/GeoPackage reproductibles avec React, FastAPI, GeoPandas et PostGIS.
